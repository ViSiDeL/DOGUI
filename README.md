# Design-Oriented Graphical User Interface (DOGUI)
DOGUI - Clark Atlanta University's Generative AI Software System for education, developed in partnership with IBM.

Fully developed by CAU's Dual Degree Engineering students, members of the Visualization, Simulation, and Design Laboratory. View more info at http://visidel.cau.edu/.

In collaboration with IBM.

## 📂 Repository Structure

Below is an overview of the folder structure and what each directory contains.

### 📁 cau-genai
This folder contains the core application scripts, divided into two subdirectories:
- **dogui/** – The main application code, including its core logic and components.
- **dev_scripts/** – Scripts used for development and feature prototyping.

### 📁 documentation
This folder holds all relevant documentation for the project. Guides, reports, diagrams, etc

### 📁 resources
A collection of useful assets, templates, or data files for the project.
- Samples & Examples
- Guides & Cheatsheets

### 📁 training
Training Materials
- workshop files
- other training session file
